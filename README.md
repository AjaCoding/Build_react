# Build_my_react
Using Javascript to render a webpage. Building my own version of react.js, and pairing it with a UI for easy web-building.

Html file for output of react built DOM: index.html
User input form html page: builder.html (for several versions there is an old_builder.html(work in progress custom form), big_builder.html(fully formatted and nice UI form created in collab with Claude Code), and basic_builder.html(very basic version of big_builder with easily customizable portions and well documented.))
